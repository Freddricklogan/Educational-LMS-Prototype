# Educational LMS Prototype

A functional learning management system (LMS) prototype with an integrated analytics dashboard, accompanied by comparative research on existing LMS platforms and a learning analytics framework.

## Overview

This project demonstrates a modern LMS student dashboard that combines course management, assignment tracking, and data visualization into a clean, intuitive interface. The prototype is built as a single-page application that works directly in the browser, requiring no server or build process.

Alongside the working prototype, this repository includes research documentation analyzing the current LMS landscape and proposing a framework for learning analytics that drives meaningful educational interventions.

## Prototype Features

### Student Dashboard
- **Course Cards** - Four active courses (Web Development, Data Science, Cybersecurity, AI Ethics) with progress bars showing completion percentage
- **Upcoming Assignments** - Chronological list of assignments with due dates and course associations
- **Engagement Analytics** - Line chart showing weekly engagement metrics over the current semester
- **Grade Distribution** - Bar chart displaying grade distribution across courses
- **Summary Statistics** - At-a-glance stat cards for courses enrolled, assignments due, current GPA, and completion rate
- **Sidebar Navigation** - Dashboard, Courses, Grades, and Analytics views

### Technical Details
- HTML5, CSS3, JavaScript (ES6+)
- Chart.js for interactive data visualizations
- Responsive design with CSS Grid and Flexbox
- All code inline (single-file deployment)

## Research Documentation

### LMS Comparative Analysis
`research/lms-comparative-analysis.md`

An in-depth comparison of four major LMS platforms -- Canvas, Blackboard, Moodle, and D2L Brightspace -- evaluating features, usability, analytics capabilities, integration ecosystems, accessibility, and total cost of ownership.

### Learning Analytics Framework
`research/learning-analytics-framework.md`

A comprehensive framework for implementing learning analytics in educational institutions, covering data collection strategies, key metrics, predictive modeling, intervention triggers, ethical considerations, and implementation guidance.

3. The dashboard loads with sample data demonstrating all features
